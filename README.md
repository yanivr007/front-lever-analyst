# Front Lever Analyst

אפליקציית PWA לניתוח front lever מהמצלמה של הטלפון. הכול רץ ונשמר על המכשיר – שום סרטון לא נשלח לשרת.

## מה יש
- **טיימר אוטומטי** – מתחיל כשנכנסים לצורה (גוף אופקי, תלוי על הידיים) ונעצר כשיוצאים ממנה.
- **ציון צורה 0–100** – אופקיות, קו אגן, מרפקים, ברכיים (לפי הווריאציה), ומשוב בזמן אמת על התיקון החשוב ביותר.
- **וריאציות** – זיהוי אוטומטי של tuck / advanced tuck / one leg / half lay / full, או בחירה ידנית (straddle – ידני בלבד, אי אפשר להבדיל מהצד).
- **נגטיבים** – משך הירידה, זמן באזור ±20° מהאופק, והזווית שבה הנפילה הכי מהירה.
- **מה נשבר ראשון** – השוואת סוף ההחזקה לתחילתה, עם רמז לחולשה אפשרית.
- **התקדמות** – שיאים, גרפים לפי יום, דפוסי כשל חוזרים, פירוט כל סט, גיבוי/שחזור לקובץ.
- **ניתוח סרטון קיים** מהגלריה.

## הרצה
```
npm install
npm run dev      # פיתוח
npm test         # בדיקות יחידה ללוגיקת הניתוח
npm run build    # פלט ב-dist/
```
המצלמה דורשת HTTPS (או localhost).

## התקנה בטלפון (אנדרואיד)
האפליקציה נארזת כ-APK פרטי (Capacitor) – בלי אתר פומבי, והכול כולל מודל הזיהוי נמצא בתוך האפליקציה.
כל push בונה APK חדש ב-GitHub Actions (`.github/workflows/android.yml`):
Actions → הריצה האחרונה → Artifacts → `front-lever-apk` → לחלץ את ה-zip ולהתקין את `front-lever.apk`.
כל הגרסאות חתומות באותו מפתח, כך שעדכון מותקן מעל הקודם וההיסטוריה נשמרת.

## מבנה
- `src/analysis.ts` – גיאומטריה: זוויות, סיווג וריאציה, ציון.
- `src/tracker.ts` – זיהוי תחילת/סוף סט, סיכום, זיהוי דפוס כשל.
- `src/train.ts` – מסך המצלמה. `src/history.ts` – מסך ההתקדמות.
- `src/pose.ts` – טעינת MediaPipe Pose Landmarker.
